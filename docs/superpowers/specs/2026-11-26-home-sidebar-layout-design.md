# 首页侧栏与图书滚动布局设计

## 目标

在不改变首页现有功能和回调语义的前提下，参考提供的视觉方向，将分类筛选移动到左侧面板，并让分类与图书内容在各自区域内滚动。

## 交互与布局

- 首页保持现有的添加图书入口、搜索、分类筛选、打开图书和书籍操作菜单。
- 首页内容改为两列：左侧为导航/筛选面板，右侧为添加入口与图书列表。
- 左侧面板包含首页标题、搜索框和全部分类；分类过多时仅左侧面板纵向滚动。
- 右侧图书区域占据剩余宽度，并在内容超过视口高度时纵向滚动。
- 当前分类仍由同一个 React 状态驱动，点击分类只改变 `filterCatalog` 的输入。
- 窄窗口下两列退化为上下布局，保证书名、操作菜单和搜索框仍可用。

## 视觉边界

- 复用现有 `--page`、`--chrome`、`--card`、`--line`、`--accent` 等设计 token，不修改颜色 token。
- 侧栏通过背景层次和现有分隔线表达边界，不增加新的装饰性组件。
- 现有书籍卡片、封面、构建进度、同步状态、重命名状态和菜单样式保持不变。

## 实现范围

- 修改 `apps/desktop/src/Home.tsx` 的首页容器结构与语义分区。
- 修改 `packages/ui/src/app.css` 中首页相关布局和响应式规则。
- 如有必要，增加首页渲染测试，验证分类按钮仍筛选对应书籍，且布局容器具有独立滚动约束。
- 不修改数据模型、桥接接口、分类算法、书籍操作回调或其他页面。

## 验证

- 运行首页相关测试和全量 `bun test`。
- 运行四项目 typecheck。
- 运行 `cd apps/desktop && bun run build`。
- 使用 `cd apps/desktop && bun run dev` 检查桌面布局：分类较多时左栏可滚动，图书较多时右栏可滚动，窄窗口不发生横向溢出。
